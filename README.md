Projeto de IA — Previsão de Diabetes

## OBJETIVO
Construir um modelo de Machine Learning capaz de prever a progressão do diabetes
com base em características clínicas de pacientes.

## TIPO DE PROBLEMA
Regressão supervisionada.

## DATASET
Dataset `load_diabetes` do scikit-learn:
- 442 indivíduos
- 10 variáveis clínicas
- Dataset limpo (sem valores ausentes)

## TECNOLOGIAS
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## MÉTRICA DE AVALIAÇAO
Erro Médio Absoluto (MAE)

## RESULTADO
Modelo treinado com desempenho satisfatório para fins educacionais e demonstrativos.

## PROJETO
- Google Colab notebook com modelo e análise.
